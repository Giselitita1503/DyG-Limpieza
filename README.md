
# DyG Limpieza de Campanas

## Descripción del proyecto

Este proyecto consiste en el desarrollo de una página web para DyG Limpieza de Campanas, realizada como parte de la Pre-Entrega de Proyecto del curso de Front-End de Talento Tech.

El sitio tiene como objetivo presentar los servicios de limpieza para cocinas gastronómicas y ofrecer un medio de contacto para potenciales clientes.

## Objetivo

Aplicar los conocimientos adquiridos sobre HTML y CSS para crear una página web organizada, accesible y adaptable a diferentes dispositivos.

## Servicios

La página presenta los siguientes servicios:

- Limpieza de campanas extractoras.
- Limpieza de filtros.
- Limpieza de fogoneros.
- Limpieza de motores.

Los servicios están dirigidos a restaurantes, bares, hoteles y otros establecimientos gastronómicos.

## Secciones de la página

- **Inicio:** presentación de la empresa y sus servicios.
- **Nosotros:** información general sobre DyG Limpieza de Campanas.
- **Servicios:** descripción de los trabajos ofrecidos.
- **Contacto:** formulario para realizar consultas.

## Tecnologías utilizadas

- **HTML5:** para estructurar el contenido de la página.
- **CSS3:** para el diseño visual y la adaptación a diferentes tamaños de pantalla.
- **Google Fonts:** para incorporar tipografías externas.
- **Flexbox y Grid:** para organizar los elementos de la página.
- **Media Queries:** para adaptar el diseño a celulares, tablets y computadoras.
- **GitHub:** para almacenar y administrar el código.
- **GitHub Pages:** para publicar el sitio web.

## Contenido multimedia

El sitio incluye imágenes ilustrativas relacionadas con el entorno de las cocinas gastronómicas. En futuras versiones, estas imágenes podrán reemplazarse por fotografías propias de los trabajos realizados.

## Formulario de contacto

La página cuenta con un formulario para que los potenciales clientes puedan ingresar sus datos y consultar por los servicios.

En esta etapa, el formulario es visual y todavía no procesa ni envía mensajes.
